Chicxulub Drive

Confidentialité

Chicxulub Drive est un outil personnel maintenu sous le compte GitHub Shirirubboy. Cette page décrit l’importeur local et ce site d’information.

Données et finalité

L’importeur utilise les métadonnées des fichiers du dossier Drive choisi, dont les noms, identifiants et tailles, pour présenter les paquets ZIP disponibles. Il télécharge le paquet sélectionné, puis lit son manifeste et ses fichiers pour vérifier leur intégrité et préparer un éventuel import local. Ces informations peuvent apparaître dans les rapports affichés sur le PC.

Autorisation Google

Le scope drive.readonly permet de lire et télécharger les fichiers de tout le Drive. Le ciblage fonctionnel du dossier « Livraisons », ou d’un autre dossier choisi, ne réduit pas cette portée OAuth. L’importeur n’envoie pas de fichiers vers Drive, ne les modifie pas et ne change pas leur partage.

Stockage et échanges

rclone s’exécute sur le PC et communique avec Google pour l’autorisation et le téléchargement. Ses identifiants OAuth et jetons sont conservés dans sa configuration locale ; l’importeur ne lit pas cette configuration et n’affiche pas ces secrets. Les ZIP téléchargés restent dans un cache local ; un import demandé séparément ajoute des fichiers au projet local. L’importeur n’envoie pas ces contenus à ce site, à GitHub ou à un service d’analyse.

Conservation et révocation

L’importeur ne programme pas de suppression automatique des ZIP conservés. L’utilisateur peut supprimer les copies locales et retirer la connexion dans les paramètres de son compte Google. Révoquer l’accès n’efface pas les fichiers déjà téléchargés ni la configuration locale de rclone.

Ce site et le contact

Ce site statique n’ajoute ni formulaire, ni outil d’analyse d’audience, ni script de suivi. Son hébergeur GitHub Pages enregistre notamment les adresses IP à des fins de sécurité, selon la politique de confidentialité de GitHub. Google traite les échanges avec ses services selon sa propre politique.

Contact : GitHub Issues du dépôt Chicxulub Drive. Les Issues étant publiques, n’y publiez aucun secret, fichier privé ou renseignement sensible.
